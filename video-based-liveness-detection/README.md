# Video-Based Face Liveness Detection

This project is a **CNN-based face liveness detection system** developed using Python, OpenCV and TensorFlow/Keras.

The system extracts frames from videos, detects faces and classifies them as **real or spoof**. The project includes scripts for dataset preparation, model training and testing.

The main purpose of the project is to demonstrate how deep learning can be used to detect spoofing attacks in face recognition systems.

---

## Features

* Frame generation from videos
* Face detection using OpenCV SSD
* CNN-based liveness classification
* Model training and testing pipeline
* Real vs fake face detection

## How to Run

1. Generate frames from videos

2. Train the liveness detection model

python src/train_model.py

3. Test the model

python src/test_model.py
